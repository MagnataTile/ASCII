Uma bela árvore de Natal em ASCII art, pedida para a IA fazer. ask AI. kkkk

Ela cresce(la ele) galho por galho, ganha festão dourado, bolas(la ele), luzinhas piscando, presentes,
uma estrela que explode em brilho e termina com **FELIZ NATAL**, tudo girando em 3D
debaixo de neve. E roda em loop infinito.

## Ver no navegador

🎄 **[Ver a árvore online](https://magnatatile.github.io/ASCII/Merrychristmas2026/view.html)**
· [só a árvore, sem o código](https://magnatatile.github.io/ASCII/Merrychristmas2026/view.html?mode=tree)

Ou abra o [`view.html`](view.html): metade de cima a árvore, metade de baixo o código rolando junto com a animação.
O botão **Só a árvore / Árvore + código** (ou a tecla `C`) alterna os modos; `?mode=tree` na URL já abre só a árvore.

## Como rodar

```bash
pip install numpy pygame-ce
python askAI/merry_christmas.py
```

`Espaço` pausa · `R` reinicia · `S` salva uma captura · `M` liga/desliga a música · `Esc` sai
